Excel Minor Project – Sales Operations Analytics

Project Overview

This project focuses on analyzing sales operations data using Microsoft Excel. It is part of the Data Analytics track at Unlox Academy.

The project simulates a real-world retail business operating across six Indian cities. It involves analyzing orders, customers, products, sales representatives, and monthly sales targets to answer business questions and support data-driven decision-making.

Objectives

- Perform data lookup operations using Excel functions.
- Identify missing values, duplicate records, and data quality issues.
- Analyze sales performance using conditional aggregation.
- Create PivotTables to summarize and compare sales data.
- Apply advanced Excel techniques for ranking and running totals.
- Generate meaningful insights to support business decisions.

Tools and Technologies

- Microsoft Excel
- VLOOKUP
- INDEX and MATCH
- SUMIFS and COUNTIFS
- IF functions
- PivotTables
- Data cleaning and validation
- Advanced Excel formulas

Dataset Description

The workbook contains the following sheets:

Sheet Name| Description
README| Project instructions and assessment details
Orders| Order transactions and sales information
Customers| Customer details and segments
Products| Product information, categories, and pricing
Sales_Reps| Sales representative details
Targets| Monthly sales targets for representatives
Q1_Lookups| Lookup function exercises
Q2_Cleaning| Data cleaning and quality checks
Q3_Aggregation| Conditional sales calculations
Q4_Pivot| PivotTable analysis
Q5_Advanced| Advanced Excel analysis

Project Workflow

1. Understand the dataset and business requirements.
2. Examine the raw data for inconsistencies and missing references.
3. Perform lookup operations to retrieve related information.
4. Clean and validate data without modifying the original data sheets.
5. Calculate sales metrics using conditional formulas.
6. Summarize and compare sales using PivotTables.
7. Apply ranking, running totals, and multiple-condition analysis.
8. Interpret the results to support business decisions.

Key Learning Outcomes

- Improved Excel formula and data analysis skills.
- Understanding of data cleaning and data quality diagnostics.
- Experience working with relational datasets.
- Ability to summarize and analyze business data.
- Practical exposure to sales operations analytics.

Conclusion

This project provides hands-on experience in Microsoft Excel for data analytics. It demonstrates how raw business data can be organized, analyzed, and transformed into useful information for evaluating sales performance and supporting decision-making.
